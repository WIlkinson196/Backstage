# v0.14 — Function Sheet + Master Operational Pack

This release deliberately follows the strongest logic from the old CRM:
- full internal Function Sheet
- operational Running Order
- explicit issue/readiness state
- version stamp
- source-data fingerprints
- controlled reissue foundation
- print-first A4 output that can be saved as PDF from the browser

Backstage improvement:
The printable documents consume the Wedding Operational Model. They do not independently calculate guest counts, payments or running-order truth.
