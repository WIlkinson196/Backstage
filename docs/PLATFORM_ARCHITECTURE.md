# Backstage Platform Architecture

Backstage is one platform with multiple experiences sharing the same data and design language.

## 1. Venue Team Web App
Primary operational product:
- Dashboard
- Enquiries / Sales
- Weddings
- Meetings
- Functions
- Calendar
- Operations
- Finance
- Reports
- My Venue
- Backstage Intelligence

## 2. Customer Portal
A separate customer-facing experience, not a cut-down staff CRM:
- Couple / organiser home
- Planning progress
- Guest information
- Menus
- Documents
- Payments
- Accommodation
- Timeline
- Venue messaging
- Tasks / outstanding information

## 3. Staff Mobile App
Operational, action-first:
- Today
- Live events
- Tasks
- Approvals
- Handover
- Alerts
- Quick notes
- Event documents
- Ask Backstage

The web UI is already responsive, but the eventual native app should be a dedicated mobile experience.

## 4. Marketing Website
Premium acquisition surface:
- Product story
- Weddings
- Meetings & Events
- Functions
- Hotel / venue categories
- AI & automation
- Customer stories
- Pricing
- Demo / lead capture

## Shared foundation
All experiences share:
- Supabase data
- Venue configuration
- Backstage design tokens
- Event/customer records
- AI knowledge layer
- Automation engine
- API/service boundaries

## Design target
Luxury hospitality, not generic admin software:
- deep charcoal/navy
- warm ivory
- champagne/gold
- restrained status pastels
- editorial typography
- real venue photography
- high whitespace
- strong hierarchy
- premium motion/interactions
